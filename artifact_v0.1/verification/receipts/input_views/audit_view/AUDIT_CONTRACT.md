# C001 adversarial audit view

This view contains PROOF.md sections 1-6, ROOT_EMBEDDING.md, exact data and core
checkers. It excludes prior success reports, discovery code and other reviews.
The proof's own mathematical claims are untrusted objects under examination.
The target is the full unrestricted five-outcome CGLMP maximum, not a numerical
optimization or a fixed-measurement claim. INPUT_IDENTITY.json identifies the
provided scientific bytes. PROOF.md is an excerpt; full-source correspondence
is coordinator-recorded in scientific_identity.json outside this view.

Attempt to break the proof. Report exact input hashes/exposure; covered claims;
strongest reproducible attacks and findings; unsuccessful attacks; limitations.
Distinguish an established counterexample, load-bearing proof error, a specific
potential gap, and inability to understand/reproduce. No PASS vote substitutes
for mathematical argument. Do not modify frozen files. Read only this view and
ordinary source interfaces as needed, and write scripts/logs/reports only in the
assigned receipt directory. Do not read other agents' outputs or historical
summaries until your first report is frozen. Shared filesystem access is possible
but not permission to exceed this boundary. Do not publish.
